# Analyses

Contrairement aux fiches de [`sources/`](../sources/README.md), qui décrivent uniquement les sources externes sans reproduire leurs données, les documents de ce dossier présentent des **valeurs calculées** à partir de sources primaires citées avec précision (tableau, identifiant, lien officiel, date de consultation) et une méthode de calcul explicite. Voir les [règles pour les analyses](../CONTRIBUTING.md#règles-pour-les-analyses-analyses) et l'[avertissement](../DISCLAIMER.md) du dépôt.
