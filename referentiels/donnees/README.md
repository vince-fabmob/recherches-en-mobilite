# Référentiel des données

`catalogue_donnees.csv` indexe les jeux de données, producteurs et ressources informationnelles nécessaires aux analyses de scénarios, d’accessibilité, de demande, d’énergie et de mobilité.

| Champ | Description |
|---|---|
| `id` | Identifiant stable commençant par `DATA-` |
| `nom` | Nom descriptif de la ressource |
| `type` | Nature de la donnée ou de la ressource |
| `territoire` | Portée géographique |
| `statut_acces` | Ouvert, sur demande, à identifier, etc. |
| `source_fiche` | Fiche documentaire dans ce dépôt |
| `lien_externe` | Source ou portail externe |
