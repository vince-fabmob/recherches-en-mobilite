# Référentiel des opérateurs

`catalogue_operateurs.csv` indexe les organisations qui opèrent, administrent ou rendent accessibles des services et infrastructures de mobilité. Une entrée n’implique aucune relation commerciale, partenariat ou recommandation.

| Champ | Description |
|---|---|
| `id` | Identifiant stable commençant par `OP-` |
| `nom` | Nom de l’organisation ou de l’infrastructure |
| `type` | Rôle principal |
| `territoire` | Portée géographique |
| `source_fiche` | Fiche documentaire dans le dépôt |
| `lien_externe` | Site officiel ou source externe |
