# Référentiel des solutions

`catalogue_solutions.csv` indexe les solutions de mobilité, d’énergie et de planification de trajets qui peuvent être reliées à un signal prospectif. Une solution peut désigner un service, une norme, une technologie ou une capacité d’intégration.

| Champ | Description |
|---|---|
| `id` | Identifiant stable commençant par `SOL-` |
| `nom` | Nom de la solution |
| `type` | Catégorie fonctionnelle |
| `territoire` | Portée géographique |
| `source_fiche` | Fiche documentaire dans le dépôt |
| `lien_externe` | Source externe, s’il y a lieu |
