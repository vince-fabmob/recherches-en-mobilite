# Standards et spécifications

Cette section indexe les standards de données et d’interopérabilité pertinents pour la mobilité.

- GTFS
- GTFS Realtime
- GTFS-Flex
- GBFS
- Mobility Data Specification (MDS)
- CurbLR
- Curb Data Specification
- Managed Transportation Lanes Feed Specification (MTLFS)
- General Modeling Network Specification (GMNS)

Les fiches détaillées seront ajoutées progressivement avec un lien vers la documentation officielle de chaque standard.
